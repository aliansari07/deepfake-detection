# Web demo

Next.js front end for the deepfake detector, plus the FastAPI service in [`backend/`](backend/)
that wraps `src/inference.py`. Setup, the model checkpoint and environment variables are covered
in the [main README](../README.md#web-interface).

```bash
# From the repository root: start the API on http://localhost:8000
uvicorn website.backend.main:app --port 8000

# From website/: start the front end on http://localhost:3000
npm install
cp .env.local.example .env.local
npm run dev
```

| Path | Contents |
|---|---|
| `app/` | Pages and global styles |
| `components/` | UI components (upload, verdict card, architecture diagram) |
| `lib/modelStats.json` | Model metrics shown on the site, generated by `tools/make_site_stats.py`; do not edit by hand |
| `backend/main.py` | `POST /analyze` (video upload → verdict + Grad-CAM) and `GET /health` |

`NEXT_PUBLIC_API_ENDPOINT` in `.env.local` sets the API URL the front end calls.
